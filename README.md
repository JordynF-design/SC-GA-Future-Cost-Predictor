# SC-GA Future Cost Predictor

A Python-based forecasting project that estimates future housing prices in South Carolina and Georgia and predicts future BMW M4/M5 values using historical data, depreciation, and scenario analysis.

## Features

### 🏠 Housing Price Predictor
- Predicts future home prices
- Supports South Carolina and Georgia
- Uses historical housing growth data
- Provides estimated future price ranges
- Generates visual forecasts

### 🚗 BMW Price Predictor
- Predicts future BMW M4 Competition xDrive values
- Predicts future BMW M5 values
- Uses historical resale-value data
- Accounts for mileage and vehicle age
- Provides depreciation scenarios

### 📊 Comparison Tools
- Compare South Carolina vs. Georgia housing growth
- Compare BMW M4 vs. M5 future values
- Conservative, base, and high-growth/depreciation scenarios
- Generates graphs using Matplotlib

## Technologies

- Python
- Pandas
- Matplotlib
- Historical housing data
- Historical BMW market-value data
